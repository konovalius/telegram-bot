# Telegram-бот с подключённой LLM

Бот принимает сообщения в Telegram, отправляет их в языковую модель и
возвращает ответ. Помнит контекст диалога, умеет переключать модель на лету.
Работает с любым OpenAI-совместимым API, поэтому провайдера можно менять
без правок кода — только `.env`.

## Запуск за 5 минут

**1. Токен бота.** Напишите [@BotFather](https://t.me/BotFather) → `/newbot` →
имя и username → получите строку вида `123456789:AAE...`

**2. Бесплатный ключ к модели.** Любой на выбор:

| Провайдер | Где взять ключ | Бесплатный лимит | Чем хорош |
|---|---|---|---|
| **Groq** | console.groq.com/keys | ~30 запросов/мин, 14 400/сутки | Очень быстрые ответы |
| **OpenRouter** | openrouter.ai/keys | ~20 запросов/мин | Много моделей одним ключом |
| **Google Gemini** | aistudio.google.com/apikey | 250+ запросов/сутки на Flash | Контекст 1M токенов |
| **Ollama** | локально, без ключа | без лимитов | Полная приватность |

Для старта рекомендую Groq: лимиты самые щедрые, карта не нужна.

**3. Настройка и запуск.**

```bash
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN и LLM_API_KEY
python bot.py
```

Готово — пишите боту в Telegram.

## Команды

| Команда | Действие |
|---|---|
| `/start` | Приветствие, сброс контекста |
| `/new` | Очистить историю диалога |
| `/model` | Переключить модель кнопками |
| `/help` | Справка |
| `/stats` | Счётчики запросов и ошибок (только для `ADMIN_IDS`) |

## Структура

```
bot.py       — хендлеры, антифлуд, разбивка длинных ответов
llm.py       — клиент к API, обработка ошибок, пресеты моделей
config.py    — настройки из .env
history.py   — контекст диалога (в памяти или SQLite)
test_bot.py  — тесты без сети
```

## Что уже учтено

- **Лимит Telegram 4096 символов** — длинные ответы режутся по абзацам,
  код-блоки не рвутся посередине.
- **Индикатор «печатает…»** обновляется, пока модель думает.
- **Внятные ошибки** вместо трейсбеков: неверный ключ, исчерпанный лимит,
  недоступная модель, таймаут — каждый случай со своим текстом.
- **Антифлуд**: интервал между запросами и блокировка параллельных генераций
  от одного пользователя, чтобы не сжечь квоту провайдера.
- **Невалидный Markdown** от модели не ломает отправку — фолбэк на plain text.

## Настройка под себя

Характер бота задаётся одной переменной в `.env`:

```env
SYSTEM_PROMPT=Ты технический консультант. Отвечай кратко, с примерами кода.
```

Ограничить доступ (бот по умолчанию открыт всем, кто его найдёт):

```env
ALLOWED_USER_IDS=123456789,987654321
```

Свой id узнать у [@userinfobot](https://t.me/userinfobot).

## Персистентная история

По умолчанию контекст живёт в памяти процесса и теряется при перезапуске.
Чтобы сохранять в SQLite, в `bot.py` замените:

```python
from history import SqliteHistory
store = SqliteHistory("history.db", limit=settings.history_limit)
```

Интерфейс совпадает, остальной код менять не нужно.

## Хостинг

Бот работает на long polling — публичный IP и webhook не нужны, запустится
где угодно. Для постоянной работы на сервере:

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Дальше systemd-юнит с `Restart=always` либо `docker run -d --restart unless-stopped`.
Подойдёт любая VPS за 200 ₽/мес, ресурсов бот почти не потребляет.

## Безопасность

`.env` содержит токен бота и API-ключ — не коммитьте его в git.
Добавьте в `.gitignore`:

```
.env
history.db
__pycache__/
```
